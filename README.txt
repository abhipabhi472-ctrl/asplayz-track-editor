Asplayz Track Editor Bot - Colab Setup

1. Google Colab lo zip extract chesi `/content/asplayz-track-editor` folder lo pettandi (or zip lo unna `asplayz-track-editor` folder ni `/content/` loki extract cheyyandi).
2. `run_colab.py` lo unna code ni Colab cell lo run chesthe bot background lo start avthundi (`RUNNING | PID=... | EXIT=None`).
3. Telegram lo `/start` pampthe welcome menu (`Functions`, `Commands`, `Destination`, `Close`) vastundi.
4. Video/MKV file pampthe `Audio`, `Rm Audio`, `Format`, `Subs`, `Rename File`, `Dest`, `Save & Process`, `Cancel` options vasthayi.
